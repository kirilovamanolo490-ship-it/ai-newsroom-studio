# AI早晚报制作与网页展示

当前有效范例为2026年10月13日早报。10月10日至12日的试验页面、旧封面/成片、过时设计与重复工程已经按用户要求移出工作区；清理清单在 research/editions/cleanup-2026-10-13.json。

## 唯一生产数据

每期使用 research/evidence/YYYY-MM-DD/morning 或 evening 中的 report.json、narration-draft.json、真实截图、原图/短媒体和配音回执。原发布时间、修改时间、发现时间、素材采集时间分别记录。来源库、raw snapshots、去重水位与官方品牌主缓存保留，用于后续制作。

## 视频

通用 Remotion DailyReport 使用V7封面与自适应正文布局。Seed TTS 2.0 Vivi女声每场连续合成，字幕对齐服务返回的真实词时间戳。生成后检查实际MP4、音轨、字幕和章节；成片哈希及验收回执对应同一报告指纹。

```sh
research/.venv/bin/python tools/produce_daily.py --date YYYY-MM-DD --edition morning --narration research/evidence/YYYY-MM-DD/morning/narration-draft.json --render-video --preview-frames
```

## 网页

build_report.py 是唯一入口，调用 build_edition_report.py。页面顺序是本期标题/摘要、视频、消息正文和来源说明。无实验期选择器，无重复完整目录，无无关品牌画廊。真实截图与完整核验资料按消息折叠展示，高清原图可放大。

web-editorial.json 仅调整网页标题和摘要表达，事实依赖report.json；它不会改视频、配音或报告事实指纹。网页样式与交互仅使用edition-report.css和edition-report.js。

```sh
research/.venv/bin/python research/report-redesign/build_report.py --input research/evidence/YYYY-MM-DD/morning/report.json
```

## 检查与交接

production-state.json 只登记保留的成品期次。旧实验消息的最小URL/版本身份保存在reported-history.json用于去重，不恢复旧页面。来源审阅继续使用review-state.json的run游标；seen状态不等于已报道。

网页修改需实际检查桌面和手机、播放、章节、原图查看器、来源展开和页面错误，并保存独立web-verification.json。视频未改时保留原视频验收回执，新的网页验收单独登记。

## 平台发布

本地视频先通过既有完整播放、音轨、字幕、章节和画面验收，再按平台分别提交。只提交当前已绑定的平台；未绑定平台跳过，不阻塞其它平台。上传器明确返回 `submitted_unverified` 且 `exit_code=0`，或平台返回 `processing` / `public`，即视为该平台提交流程完成。成功回执后不例行打开创作者后台核验，不切换账号或重新登录确认，不重复上传。保存真实返回状态，不得写成 `independently_verified_public`。失败、账号无效、结果含糊分别记录，只有这些失败状态需要后续动作。
